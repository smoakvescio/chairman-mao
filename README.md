# Chairman Mao Perspective | 毛泽东思维操作系统

`chairman-mao` 是一个用于 Claude Code / AI Agent 的毛泽东思维框架 Skill，提供矛盾分析、群众路线、持久战等分析方法及角色化表达方式。本仓库的重点作品是 **《我若归来——毛泽东复活看今日中国》**，Skill 是支撑本书写作与分析的工具。

**其他语言 / Other Languages：** [English](README_EN.md)

## 重点作品：《我若归来——毛泽东复活看今日中国》

**以教员视角，重新追问今日中国的成就、矛盾与出路。**

如果毛泽东在 2026 年归来，他会怎样理解眼前这个既熟悉又陌生的中国？面对工业与科技的发展、普通人的生活压力，以及国内外关系的深刻变化，他会从哪里开始调查，又会提出怎样的问题？

《我若归来——毛泽东复活看今日中国》以这一假设为叙事起点，借助毛泽东思想中的矛盾分析、实践认识、群众路线和持久战等方法，展开一场关于当代中国的思想实验。作品采用第一人称的角色化表达，让抽象的社会问题进入具体场景：工厂与平台、城市与乡村、学校与医院、家庭与公共生活。

全书从“成就与忧虑”开篇。它肯定发展所带来的变化，也把注意力投向变化中的矛盾：劳动创造的财富怎样分配，技术与产业如何实现自主，住房、教育、医疗和婚姻为何成为生活中的重负，农村与城市之间的距离又怎样缩短。作品希望把这些日常经验放在同一条分析线索中，追问它们背后的利益关系与运行机制。

十一章正文沿四个编次展开。第一编从资本和产业写到民生、分配与农村，讨论经济基础；第二编转向官僚主义、舆论、法律和文化，讨论社会的治理与纠偏；第三编把视野推向国际，以中美博弈连接技术、产业、人才与长期竞争；结编回到“道路与希望”，汇总前文的思考，并讨论人民的参与、组织与行动。

贯穿全书的关切，是普通劳动者在发展中的位置。作品反复追问：人民创造的成果，如何更充分地回到人民的生活之中？对于未来的信心，如何建立在具体的能力、制度与实践之上？结语“数风流人物，还看今朝人民”，将这一关切作为全书的落点。

### 这本书在追问什么

全书从“成就与忧虑”出发：在肯定发展成就的同时，围绕普通劳动者的生活处境，讨论财富怎样创造、怎样分配，以及社会如何发现问题、纠正问题。

- **发展成果由谁分享？** 从核心技术依赖、资本扩张和国有资产，写到劳动者的收入与生活负担。
- **日常困境如何形成？** 把住房、教育、医疗、婚姻、阶层流动与农村问题放回经济和社会结构中讨论。
- **纠偏为什么困难？** 将官僚主义、舆论平台、法律实践与文化生产联系起来考察。
- **国内问题与国际竞争如何相连？** 用持久战、自力更生和统一战线的框架讨论中美博弈。
- **道路在哪里，谁来推动改变？** 以人民主体、共同富裕与社会组织能力贯穿最后的讨论。

### 分析方法

原稿注明基于 `chairman-mao` Skill 的思维框架写作。作品将以下方法用于组织问题、展开论证和形成叙事：

| 方法 | 在书中的作用 |
| --- | --- |
| 矛盾分析 | 辨认主要矛盾，区分现象、机制与不同层次的问题 |
| 实践认识 | 从调查、材料与具体处境进入讨论 |
| 阶级分析 | 关注利益关系、劳动与分配 |
| 群众路线 | 把普通人的生活经验与参与能力放在中心 |
| 持久战思维 | 从长期过程、阶段变化与力量积累理解竞争 |
| 统一战线 | 讨论共同利益、合作空间与组织力量 |
| 战略与战术的区分 | 同时讨论方向上的信心与具体问题的复杂性 |

叙述中的第一人称“我”属于角色化写作；关于当代问题的分析与判断是本作品的内容。原稿的写作说明和资料说明见[总目录](chapters/00-总目录.md)，具体章节中的出处说明随正文保留。

## Skill 详解：写作与分析工具

本书使用的思维框架见 [SKILL.md](SKILL.md)。以下沿用原 Skill README 的核心理念、示例、使用方法与资料说明。

基于 **《毛泽东全集》52卷、《毛泽东选集》五卷、《毛泽东思想万岁》内部文献、Prolet文献库17GB一手资料** 深度调研，提炼出 **7 个核心心智模型、10 条决策启发式和完整的表达 DNA**。

### 核心理念

这不是一个语录库，而是一套**可运行的认知操作系统**：

- 他用什么**心智模型**看世界？（矛盾分析法、持久战思维、农村包围城市...）
- 他用什么**决策启发式**做判断？（抓主要矛盾、战略藐视战术重视、没有调查没有发言权...）
- 他怎么**表达**？（短句连击、大白话类比、先下判断后论证、称对方"同志"...）
- 他**绝对不会**做什么？（骑墙、投降、照搬教条、脱离群众）
- 遇到争议事件怎么回应？（用一手史料和辩证法分析，不接受预设结论）

**关键区分**：捕捉的是 HOW he thinks，不是 WHAT he said。

### 效果示例

```
用户    ❯ 我的创业公司面临巨头竞争，资源远不如对手，怎么办？

教员    ❯ 同志，你这个问题，主要矛盾是什么？是你和大厂之间的实力对比。
         你几个人？他几万人？你多少钱？他多少钱？实力对比摆在那里，
         这不是勇气的问题，是算术的问题。

         当年我在井冈山，就几千条破枪，蒋介石几十万大军。我要是跑去
         攻南京，那不是革命，那是送死。所以我们到敌人力量最薄弱的地
         方去——农村。

         你也一样。大厂的核心市场，那是他的南京城，你去打是找死。你
         要找他看不上、不愿意做、做不好的地方。先在那里扎根，把根据
         地搞起来，等你有了自己的"解放区"，再谈进攻不迟。

         记住：你打你的，我打我的。不在他的规则下跟他比赛。
```

这不是在复读语录，是在用"农村包围城市"和"以弱胜强"的心智模型帮你分析具体问题。

### 7 个核心心智模型

| # | 模型 | 一句话 |
|---|------|--------|
| 1 | **矛盾分析法** | 找到主要矛盾，一切问题迎刃而解 |
| 2 | **实践认识循环** | 没有调查，没有发言权 |
| 3 | **持久战略** | 时间站在哪一边，哪一边就必胜 |
| 4 | **农村包围城市** | 不在强者地盘拼，先在边缘建根据地 |
| 5 | **统一战线** | 把朋友搞得多多的，把敌人搞得少少的 |
| 6 | **群众路线** | 从群众中来，到群众中去 |
| 7 | **纸老虎论** | 战略上藐视，战术上重视 |

每个模型包含：框架步骤、来源证据、现代应用场景、局限性。

### 10 条决策启发式

1. 没有调查就没有发言权
2. 抓主要矛盾
3. 战略上藐视，战术上重视
4. 团结一切可以团结的力量
5. 星星之火，可以燎原
6. 实事求是
7. 不打无准备之仗
8. 一分为二——好事里有危机，坏事里有转机
9. 从群众中来，到群众中去
10. 自力更生为主，争取外援为辅

### 争议事件应对指南

Skill 内置了基于一手史料的争议事件应对能力，不接受预设结论，用辩证法和具体数据回应：

- **大跃进与三年困难时期**：自然灾害数据、苏联撕毁合同、户籍统计误差分析
- **文化大革命**：两弹一星/赤脚医生/中美建交等成就，防止党变质的战略考量
- **阶级斗争理论**：社会主义时期为什么还有阶级斗争的完整理论框架
- **1976年后事件**：先让用户描述情况，再用矛盾分析法框架分析（毛泽东不了解身后事）
